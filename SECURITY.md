# Security Policy

## Reporting a Vulnerability

Please report security issues privately rather than opening a public GitHub issue.

Contact:

- Aidan Hall
- Email: <aidan.hall34@outlook.com>
- GitHub: [@aidanhall34](https://github.com/aidanhall34)

Include as much detail as you can safely share, including the affected workflow, script, configuration file, or deployed
site behavior, plus any reproduction steps.

## Scope

Security reports are welcome for this repository's GitHub Actions workflows, deployment tooling, repository
configuration, and generated public site.

Do not include secrets, tokens, private vault contents, or other sensitive data in reports unless explicitly requested
after initial contact.

## Response

I will review reports as soon as practical and follow up with next steps, mitigations, or a fix plan.
